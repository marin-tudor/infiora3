Per-page rules

  • Cover page: logo + hotel name + address QR (if address is set)
  • WiFi page: SSID + password + auto-connect QR code
  • Blog/activities: up to 4 sections per page, each with max 5 photos
  • Each link button = its own page (never mixed)
  • Section with phone/address gets a scannable QR code
  • Background color matches the app's chosen color scheme

Translation

  • PDF uses the same translated data already loaded in-app
  • No extra API calls — translation dictionary is cached in memory
  • Language shown in PDF footer (e.g. "Guide in English")
  • Button label for download also translated ("Download offline guide")
💡 Question for you: For blog sections that have many sections (e.g. 8 activities), should overflow continue onto a second page for the same button, or should we cap at 4 and indicate "see full guide online"?
